# PokeHabit APK v1.0.8 + Web v1.7.134 — 원터치·요일알림·수면추정

## 제공 범위

- APK 홈 위젯(4개 원터치 버튼): 기존 커스터마이징 라이프 이벤트 중 4개까지 설정하고, 앱을 열지 않고 바로 기록합니다. 하루 1회형 버튼을 다시 누르면 최신 기록으로 수정됩니다. 로그는 APK 내부 SharedPreferences 큐에 먼저 저장되며, 로그인한 해당 트레이너의 WebView가 다음에 열릴 때 전송됩니다. 웹 저장 성공 후에만 큐 항목을 승인·삭제합니다.
- Android 기기 사용 기록 기반 기상·취침 후보: 사용자 동의 하에 사용 정보 접근을 허용했을 때, 잠금 해제·실제 사용 중 야간 3~13시간 미사용 구간을 추론합니다. UI에서 추정 후보를 확인하고 각각 '기상/취침으로 기록'을 누를 수 있습니다. 기존 수동 기록은 덮어쓰지 않습니다. 권한이 없거나 충분한 신호가 없으면 어떤 자동 추정 UI도 추가 표시되지 않습니다.
- 알림 반복: 매일, 평일, 주말, 매주 지정 요일, 원하는 복수 요일, 지정 날짜 1회. 예전 매일 알림은 그대로 매일로 이동합니다.
- 오늘의 모험 브리핑: 퀘스트별 '오늘 알림' 시간 입력 및 해제. 퀘스트가 완료되면 다음 네이티브 동기화 때 예약에서 제외합니다. 예약된 한 번 알림은 다음 날 다시 울리지 않습니다.
- 웹/PWA 유지: 네이티브 연결 여부를 탐지해 알림은 기존처럼 PWA가 보이는 동안만 표시되며, 기기 사용 추정이 없으면 원래 수동 기록 UI를 유지합니다. 웹/PWA에서는 과거 APK 백업에 추정 데이터가 포함되어 있어도 추정 후보 UI를 노출하지 않습니다.
- 웹의 기존 달력/기록/퀘스트/JSON 백업 포맷 유지. 새 필드는 과거 백업에서 안전한 기본값을 갖습니다.

## 배포 작업 순서

1. **웹 GitHub Pages 저장소**에 `web/index.html`과 `web/sw.js`를 먼저 적용합니다. `web/moves.html`은 기존 최신 원본을 그대로 포함합니다. 브라우저에서 v1.7.134와 개인 알림 메뉴를 확인합니다.
2. **APK GitHub Actions 저장소**에는 이 ZIP의 `app/`, `.github/workflows`, `build.gradle`, `settings.gradle`, `gradle.properties`, `tests/`, `scripts/` 등을 기존 경로 그대로 적용합니다.
3. 기존 워크플로의 `POKEHABIT_DEBUG_KEYSTORE_B64` 시크릿을 **변경하지 마세요**. 서명키를 바꾸면 기존 APK 업데이트가 설치 충돌을 일으킬 수 있습니다. 반드시 기존 시크릿으로 v1.0.8 APK를 빌드하십시오.
4. 위젯은 갤럭시 홈 화면 빈 곳 길게 누르기 → 위젯 → PokeHabit을 추가합니다. PokeHabit APK로 한 번 로그인하면 최근 선택한 트레이너의 이벤트 버튼이 동기화됩니다. 라이프 이벤트 설정에서 위젯 버튼을 변경할 수 있습니다.
5. 앱 설정 → 개인 알림 → 알림 권한·정확한 알람 권한을 승인하고 테스트를 수행합니다. 같은 화면에서 기상·취침 추정용 '사용 기록 접근 설정'을 별도로 허용할 수 있습니다.
6. **기기별 APK, 브라우저 PWA 저장 데이터는 서로 독립적**이므로 공유한 JSON 백업/복원 정책은 기존과 동일합니다. 위젯 기록은 해당 APK/WebView 계정으로만 전달됩니다.

## 중요 제한

- 현재 제공 파일은 **APK로 컴파일된 파일이 아니라 소스 패키지**입니다. 컴파일, 실제 Android 기기 테스트, 앱 위젯 동작, 설치 업데이트 검증은 반드시 빌드 환경에서 수행해야 합니다.
- 사용 기록 기반 추정값은 '수면 시간'이 아닙니다. 야간에 화면만 자동 점등될 수 있어 실제 잠든 시각·기상 시각과 다를 수 있으므로 참고 후보로만 표시하고 사용자가 수동 채택하게 설계했습니다.
- UsageStats는 사용자가 권한을 주어야 하며 기기 및 OS에 따라 기록 보존 기간과 이벤트 제공 범위가 제한될 수 있습니다. 실제 수면 구간 추정을 보장하지 않습니다.
- PWA는 실행 화면이 닫혀 있을 때 브라우저 자체만으로 예약된 개인 알림을 보장하지 않습니다. APK는 OS 알람을 예약하지만 기기 절전·정확한 알람 권한 정책 때문에 지연될 수 있습니다.
- 배경 상주 추적·포그라운드 서비스·마이크·카메라 등 민감 권한은 추가하지 않았습니다.
- 외부 GitHub Pages에서 실행되는 스크립트의 네이티브 연결은 기존 신뢰된 오리진 검증 로직을 그대로 사용합니다.

## 검증 목록

- 수행: JavaScript `node --check`, 알림 반복 규칙(주말/평일/매주/커스텀/1회), 이전 매일 알림 migration, 후보 없을 때 PWA 기존 화면 유지, Android XML 파싱, 소스 정적 확인.
- 미수행: 실제 Android SDK Gradle 빌드, 갤럭시 설치/위젯 클릭, 잠금 해제 히스토리 정확성 측정, 알림 운영체제 발송 테스트.

## 권장 실기기 QA

- PWA: 기존 매일 알림 불러오기 → 새 옵션 선택 → 저장/복원 → 앱이 보일 때 테스트. 미추정이면 기상/취침 영역 이전과 동일한지 점검.
- APK: 기존 서명으로 업데이트 설치, 4개 위젯 버튼 변경/클릭/앱 재실행/중복 방지, 사용자 계정 전환, 자정 전후 취침 분류, 화면 잠긴 상태의 퀘스트 1회 알림 및 반복 요일 알림 테스트.
- 수면 추정: 권한 OFF → UI 미노출; 권한 ON → 오전 기상 후보 생성; 직접 기록 있으면 덮어쓰지 않음; 후보 채택 후 라이프 이벤트·생활 리듬에 반영됨을 확인.
